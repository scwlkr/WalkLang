# WalkLang Trademark Policy

WalkLang is the official name of the programming language, compiler, documentation, and project identity created by Shane Walker / WLKRLABS.

The WalkLang source code is open source under the Apache License 2.0.

The WalkLang name, logo, and brand identity are not licensed as open source.

## You may

You may use the WalkLang name to truthfully describe:

- the official WalkLang project
- compatibility with WalkLang
- tutorials, examples, articles, and videos about WalkLang
- packages, tools, or libraries made for WalkLang
- forks clearly marked as unofficial

Examples:

```txt
A formatter for WalkLang
Compatible with WalkLang
Unofficial WalkLang fork
WalkLang tutorial
````

## You may not

You may not use the WalkLang name, logo, or branding in a way that suggests your project is official, endorsed, or controlled by Shane Walker / WLKRLABS unless you have written permission.

You may not:

* rename a fork as WalkLang
* present an unofficial build as the official WalkLang compiler
* use the WalkLang logo as your project logo
* register confusing names, domains, packages, or accounts
* imply endorsement where none exists

Examples not allowed:

```txt
The new official WalkLang
WalkLang Pro
WalkLang Compiler, by another maintainer
walklang.dev, if not controlled by the official project
```

## Forks

Forks are allowed.

Forks must use a clearly distinct name unless they are clearly distributed as unofficial builds of WalkLang.

Good:

```txt
RiverLang, a fork of WalkLang
Unofficial WalkLang build by Jane Doe
```

Bad:

```txt
WalkLang
Official WalkLang
WalkLang 2
```

## Attribution

You may say that your work is based on WalkLang, as long as the statement is accurate and does not imply official endorsement.

Example:

```txt
This project is based on WalkLang, created by Shane Walker / WLKRLABS.
```

## Permission

For permission to use the WalkLang name, logo, or branding beyond this policy, contact the project owner.
